# DevSpace

DevSpace is an iOS application designed to discover the popular and trending libraries across various programming languages. By leveraging the GitHub API, it provides a curated view of top-tier repositories based on real-time community engagement.

## 🚀 Features
- **Language-Based Discovery**: Browse libraries categorized by programming languages like Python, Swift, and Java using a nested UITableView and UICollectionView architecture.
- **Smart Sorting**: Automatically fetches and displays repositories with the highest fork and star counts.
- **Linking**: View specific repository details and jump directly to the source on GitHub with a single tap.
